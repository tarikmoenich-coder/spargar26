**Betreff: Anfrage — Angebot über 140 fest einzubauende 2D-Barcode-/QR-Scan-Module (Presentation-Mode, RS232)**

Sehr geehrte Damen und Herren,

wir betreiben einen landwirtschaftlichen Betrieb mit Spargel- und
Gemüseanbau und rüsten derzeit 140 selbstfahrende Erntemaschinen mit
IoT-Technik aus (Teltonika TRB246 als Gateway je Maschine). Dafür suchen wir
ein fest einzubauendes **2D-Scan-Modul**, das auf einer seriellen
Schnittstelle (RS232 bzw. TTL/UART) direkt an diesen Router angeschlossen
wird und dort QR-Codes auf Hartplastik-Karten liest (Mitarbeiter-Badges und
Kisten-Kennungen).

Wir bitten Sie um ein **Angebot über 140 Stück** sowie gerne mehrere zu
unserem Einsatzzweck passende Modell-Alternativen (z. B. gute/bessere
Ausführung) zur Auswahl.

## Einsatzzweck (kurz)

- Montage fest in einem Elektronik-Gehäuse an jeder Erntemaschine, hinter
  einem kleinen, wettergeschützten Sichtfenster — kein Handscanner.
- Der Fahrer hält eine Hartplastik-Karte (ca. Kreditkartenformat) kurz vor
  das Lesefenster; das Modul soll **automatisch auslösen**, ohne
  Tastendruck/Trigger.
- Ganztägiger Dauereinsatz auf dem Feld, über eine komplette Erntesaison,
  bei jedem Wetter.
- Gelesen wird ausschließlich **QR-Code**, Leseabstand gering (Karte wird
  direkt vors Fenster gehalten, wenige Zentimeter genügen).

## Pflicht-Anforderungen

| Merkmal | Anforderung |
|---|---|
| **Code-Typ** | 2D-Imager, QR-Code (Data-Matrix-Fähigkeit als Plus, nicht zwingend) |
| **Schnittstelle** | **RS232** (alternativ TTL/UART-Pegel mit Pegelwandler akzeptabel), konfigurierbare Baudrate, 8N1 |
| **Betriebsmodus** | **Presentation-/Dauerscan-Modus** — löst automatisch bei Code-Erkennung aus, kein manueller Trigger nötig |
| **Schutzart** | **mindestens IP54** (Staub- und Spritzwasserschutz); IP65 bevorzugt, falls im Angebot verfügbar |
| **Bauform** | **Einbaumodul/OEM-Scan-Engine zum Festverbauen**, kein Hand-/Tischscanner |
| **Umgebung** | Freiland-Dauereinsatz: Temperaturbereich bitte laut Datenblatt angeben; Vibrations-/Erschütterungsfestigkeit (mobile landwirtschaftliche Maschine) |
| **Hersteller** | **Markenhersteller** (z. B. Honeywell, Newland, Zebra, Datalogic o. Ä.) — bei 140 Dauereinsatz-Geräten ist uns Ausfallsicherheit wichtiger als der niedrigste Einkaufspreis |
| **Stromversorgung** | Kompatibel mit 5 V/TTL- bzw. den I/O-Pegeln eines Industrie-Routers (Teltonika TRB246) |

## Wünschenswert (kein Ausschlusskriterium)

- Optische/akustische Bestätigung bei erfolgreichem Scan.
- Hohe Fehlerkorrekturstufe / zuverlässiges Lesen auch bei leicht
  verschmutztem oder beschädigtem Code.
- Eine **scannerseitige Drossel-/Entprellfunktion** (z. B. „derselbe Code
  wird erst nach X Sekunden erneut gemeldet") — reduziert bei uns die
  Datenmenge und vereinfacht die Auswertung.
- Lange Verfügbarkeit/Ersatzteilgarantie über mehrere Jahre, da wir über
  mehrere Saisons hinweg nachbestellen wollen.
